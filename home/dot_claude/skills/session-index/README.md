# session-index

会話の中で定義した「案A」「選択肢2」「方針B」のようなラベルを索引にし、後の返答でそのラベルに触れたとき、返答の下に `↳ 案A` のチップを出す Claude Code の mod（hooks モジュールだけのプラグイン）。チップにマウスを重ねると、定義したときの本文がカードで開く。

長いセッションで「案A にする場合は…」と返ってきて、案A が何だったかを遡って探す手間をなくすのが目的。

## 何を定義として拾うか

行の頭にラベルがあり、次のどれかの形になっているもの。

- 見出し（`## 案A`）。次の同じか上の階層の見出しまでを本文とする
- 太字（`- **案A**: …`、`**案A** …`）。空行か次の項目までを本文とする
- ラベルの直後に `:`・`（` が続く行（`- 案A: …`、`案A（推奨）`）
- 表の 1 列目（`| 案A | … |`）。その行だけを本文とする
- AskUserQuestion の選択肢のラベル（`案A（推奨）`）。質問文と説明を本文とする

文中の「案A にすると」のような言及は定義として扱わない。拾うラベルは `案` `選択肢` `オプション` `パターン` `プラン` `方針` `アプローチ` `Option` `Plan` `Approach` の後に英数字 1〜2 文字が続くものと、`A案` の形。全角の英数字は半角にそろえて同じラベルとみなす。

同じラベルが何度も定義されたとき（別の話題でまた案A〜C を出したとき）は、その返答より前の最後の定義を見せる。

## 仕組み

- 索引は、セッションの開始時と各ターンの終わりに会話の履歴（`$.session.messages`）を読み直して作り、セッションの state に置く
- compact で古い発言が要約に置き換わると、そこにあった定義は履歴から消える。前回の索引にしか無いラベルは残し、カードに「compact 前の定義」と出す
- チップとカードは、返答のブロック（`AssistantMessage`）の描画に足している。本文の Markdown は 1 つの部品として描かれ、語ごとに分けられないので、ラベルの語そのものにはホバーを付けられない
- カードは本文の上に重ねず、チップの行の下に差し込む。端末には背景を塗る色が無く、重ねると下の本文が透けるため

## 制約

- ホバーはマウスの位置を受け取れる画面でだけ効く（端末なら fullscreen の描画）。受け取れない画面ではチップだけが出る
- 書いている途中の返答は索引にまだ無いので、その時点の最後の定義を見せる

## 読み込まれ方

chezmoi が `~/.claude/skills/session-index/` に配り、Claude Code が skills フォルダのプラグインとして起動時に読み込む。変更は `scripts/apply-merged.sh` で配った後、セッションを開き直すと効く。

## テスト

```
claude plugin validate ~/.claude/skills/session-index
claude plugin test ~/.claude/skills/session-index
```
