# GitHub への投稿

- Issue / PR へのコメント（レビュー指摘への返信、進捗報告など）は、投稿する前に必ず本文案をユーザーに見せて確認を取る。承認を得てから投稿すること。指示なしに勝手に投稿しない

# 何をどこに書くか

リポジトリ内のコード規約を優先する。規約が無い部分では以下を既定とする。

- コード — How（どう実現しているか）
- テストコード — What（何を満たすべきか）
- コミットログ — Why（なぜ変えたのか）
- コードコメント — Why not（なぜ他の手を採らなかったか）

いずれも必要以上に書かない。コードを読めば分かる How をコメントで繰り返さない。

# 日本語

コミットログ・PR 本文・ドキュメント・コメントを日本語で書くときは yomiyasu スキルを使う。
